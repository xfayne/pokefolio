# Pokefolio visual design references

Approved design round: 2026-11-19–20. Related: [Issue #4](https://github.com/xfayne/pokefolio/issues/4).

These files are versioned design references, not implemented or tested application screens. All card art, amounts and personal names in the mockups are illustrative demo content.

Read [decisions](decisions.md) before implementing: written corrections override stale details in an image. [Tailwind specification](design-system.md).

## Status

- Approved: main design system and all images in `approved/`, subject to the corrections below.
- Wishlist: page heading Wishlist; internal tabs **Cards / Deals**. The image still contains the old inner Wishlist label.
- Transactions: remove the History / Shipments strip visible in the approved history image. Tracking stays inside transaction details. Monthly balance is a small plain amount, not a box.
- Deals: `proposals/wishlist-deals-proposal.png` is a saved baseline requiring refinements, not final approval.
- Settings: screen-specific mock deferred by the owner; rejected proposals are not included.
- Analyze: Classic Red is the approved screen-specific exception to the shared blue palette.

## Approved Transactions Overview — 2026-11-20

Overview / History replaces the earlier single-history decision. Overview includes period selection, purchase spending, net sale receipts, net cash flow, monthly grouped bars and physical-copy activity. Month selection drills into filtered History. Net cash flow is not profit. Demo numbers are illustrative; the existing five-item bottom navigation and Analyze icon remain as previously approved, despite incidental icon differences in this new mock.
